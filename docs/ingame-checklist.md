# Проверка в игре (живой сервер Paper 1.21.11 + LuckPerms)

Подготовка: сайт с `PAYMENT_PROVIDER=test` (или `manual`), плагин настроен, `/kvip status` → «сайт доступен».

| # | Проверка | Ожидаемый результат |
|---|---|---|
| 1 | Кабинет → код, в игре `/link КОД` | «Аккаунт привязан», на сайте виден ник |
| 2 | Купить VIP (тест-оплата) | ≤30 с: сообщение в игре, префикс в чате/TAB, `/lp user <ник> info` — `kryvanta_vip` с датой |
| 3 | `/vip` | Меню, все кнопки открывают функции |
| 4 | `/size 0.5`, `/size 2` под потолком в 2 блока | Уменьшение работает; увеличение отклонено «недостаточно места» |
| 5 | Удар другого игрока при размере 0.5 | Размер → 1.0 на 15 с, затем возвращается |
| 6 | `/boat 3`, лодка на воде, W | Скорость растёт до ~14 бл/с; на льду и в чужой лодке — без ускорения |
| 7 | `/anvil`: ремонт + переименование | Списывается опыт, предмет получен; при закрытии предметы из слотов возвращаются |
| 8 | `/enchant` с 30+ уровнями и 3 лазуритами | Нижний слот — 30 уровней; списано 3 уровня и 3 лазурита |
| 9 | `/ec`, `/craft`, `/grindstone`, `/smithing`, `/loom`, `/stonecutter`, `/cartography` | Ванильные интерфейсы работают |
| 10 | `/brew`: вода ×3 + незерский нарост + огненный порошок | Через 20 с — неуклюжие зелья; закрыть/выйти/зайти — содержимое на месте |
| 11 | Стоять AFK 5 минут; затем играть | Во время AFK `/viprewards` показывает «Пауза» |
| 12 | `/kvip info <ник>`, перезапуск сервера | Прогресс награды сохранился |
| 13 | Админ → Награды → выдать набор → `/viprewards` | Награда видна и выдаётся; в истории на сайте появилась запись |
| 14 | Админ → VIP → снять | ≤30 с: группа снята, размер 1.0, содержимое /brew возвращено |
| 15 | Остановить сайт, перезапустить сервер | VIP-игроки сохраняют VIP по кэшу; `/kvip status` — «недоступен» |
